# Variable: CURRENCY\_DATA

> `const` **CURRENCY\_DATA**: `object`

Defined in: src/core/currency-data.ts:14

The full set of currencies this library supports: koala's original
tradeable-asset allowlist intersected with ISO-4217 fiat currencies
that have a real Dinero-compatible definition, plus STN/SYP/ZWL
(real fiat currencies omitted from koala's original list by
oversight) and minus ILS (deliberately unsupported) and the
non-circulating settlement/indexed units (BOV, CHE, CHW, COU, MXV,
USN, UYI, UYW) and sanctioned-region KPW. Vendored as static data
instead of depending on `@dinero.js/currencies`, which has no
stable release (see spec §2, "Dinero version decision").
